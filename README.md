Recommended before this goes live:
1. Fill in all placeholders.
2. Get a lawyer familiar with Balkan-region / EU data protection law to review both, especially the liability and data-retention sections.
3. Delete the review-checklist comment blocks once reviewed.
4. Push this folder to its own repo (or a `docs/` folder with GitHub Pages enabled) so each file has a stable public URL for the App Store / Play Store listings.
